# v2.14.0

A long-running task no longer dies when the backend reports that the selected
model is at capacity. The runtime proxy waits it out and re-sends instead of
burning through the account pool. No user configuration migration is required.

Landed as [#692](https://github.com/ndycode/codex-multi-auth/pull/692), closing
[#689](https://github.com/ndycode/codex-multi-auth/issues/689).

## Upgrade notes

No migration is required. Install the package and confirm the version:

```bash
npm i -g codex-multi-auth
codex-multi-auth --version
```

The command should report `2.14.0`.
